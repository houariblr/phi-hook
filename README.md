# Φ-Hook (Phi Hook) 🌀

**Sustainable LP Retention via Golden Ratio Mathematics for Uniswap V4**

An autonomous, parameter-free Uniswap V4 hook infrastructure engineered to replace arbitrary governance parameters and inflationary tokenomics with natural constants. By anchoring liquidity mechanics to Fibonacci sequences and Golden Ratio ($\phi$) scaling curves, the protocol aligns long-term liquidity depth with systemic rewards.

## 🔧 Core Components

### `src/PhiMath.sol`

| Attribute | Description |
|-----------|-------------|
| **Role** | Pure mathematical kernel |
| **Mechanics** | Implements fixed-point integer math to compute Fibonacci numbers and handles exponentiation of the Golden Ratio ($\phi \approx 1.618$) using a safe scale factor ($\text{SCALE} = 10{,}000$). |
| **Guarantees** | Zero floating-point calculations, preventing rounding exploits or overflow vulnerabilities during curve scaling. |

### `src/PhiHook.sol`

| Attribute | Description |
|-----------|-------------|
| **Role** | Core Uniswap V4 Hook interface |
| **Mechanics** | Implements `beforeInitialize`, `beforeAddLiquidity`, and `afterSwap`. It maps every LP position to a unique key: |

$$\text{posKey} = \text{keccak256}(\text{lp}, \text{poolId}, \text{tickLower}, \text{tickUpper})$$

| | It captures a strict $38.2\%$ protocol fee from swap fees and processes early-exit penalties into the reward pool. |

### `src/PhiRewards.sol`

| Attribute | Description |
|-----------|-------------|
| **Role** | High-precision reward engine |
| **Mechanics** | Uses a highly efficient Synthetix-style accumulated `rewardPerShareX128` tracking architecture. An LP's voting shares compound dynamically based on their holding period: |

$$\text{Shares} = \text{Liquidity} \times \phi^{\text{periods}}$$

| **Dust Management** | Includes dedicated residual tracking variables to ensure fractional wei generated by integer division are recycled into the reward index rather than being locked permanently. |

### `src/FeeCollector.sol`

| Attribute | Description |
|-----------|-------------|
| **Role** | Upgradeable fee abstraction layer |
| **Mechanics** | Acts as the `approvedCollector` for the core hook. It executes the raw Uniswap V4 settlement pattern by triggering `IPoolManager.unlock()`. |
| **Token Flow** | Tokens go directly from the `PoolManager` to the target recipient. `FeeCollector` handles the callback securely without ever storing or custodying ERC-20 tokens. |

### Dependencies

Ensure you have the Foundry toolchain installed on your Linux system (Ubuntu/Kubuntu optimized).

```bash

git clone --recursive https://github.com/your-username/phi-hook.git
cd phi-hook

# Build and compile contracts
forge build
```
